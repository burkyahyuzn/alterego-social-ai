# ALTEREGO
### Personal Future-Impact Recommendation Engine for Social Media

ALTEREGO is an AI-supported recommendation system designed to evaluate not only the immediate engagement potential of social media content, but also its predicted impact on a user's future algorithmic profile.

## Problem
Traditional social media recommender systems are primarily optimized for immediate engagement signals such as clicks, watch time, and likes. This may gradually move a user's feed away from their consciously declared content preferences.

## ALTEREGO Approach
ALTEREGO models four user states:
1. **Intended Me:** Ne görmek istediğimi söylediğim ben.
2. **Behavioral Me:** Gerçekte tıkladıklarımdan çıkan ben.
3. **Algorithmic Me:** Platform algoritmasının benim hakkımda öğrendiği ben.
4. **Future Algorithmic Me:** Mevcut etkileşim devam ederse gelecekteki ben.

## Core Metrics
* **IAI (Intent Alignment Index):** Kullanıcının bilinçli hedefiyle gerçek feed arasındaki yakınlık.
* **PFI (Predicted Feed Impact):** Bir içeriğin gelecekteki feed dağılımını ne kadar değiştirebileceği.
* **PAC (Personal Alignment Cost):** Kullanıcının hedefinden sapma maliyeti.
* **ARS (ALTEREGO Recommendation Score):** Nihai öneri puanı.
* **FAS (Future Alignment Score):** Gelecekteki feed senaryolarının uyum puanı.
